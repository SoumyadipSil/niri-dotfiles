# niri-dotfiles

Personal desktop configuration files.

## Layout

- `config.kdl`: Main Niri entry point.
- `niri/`: Niri configuration snippets included by `config.kdl`.
- `noctalia/`: Noctalia configuration.
- `fastfetch/`: Fastfetch configuration and local display assets.
- `alacritty/`: Alacritty configuration and theme.
- `kitty/`: Kitty configuration and theme.
